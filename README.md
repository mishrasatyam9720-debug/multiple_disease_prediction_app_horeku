# 🩺 Multiple Disease Prediction Web App

A Machine Learning-based web application that predicts the likelihood of multiple diseases using trained ML models. The application provides predictions for:

- 🩸 Diabetes
- ❤️ Heart Disease
- 🧠 Parkinson's Disease

The application is built using **Python** and **Streamlit** and provides an easy-to-use interface for entering patient health parameters and getting predictions instantly.

---

## 🚀 Features

- Predict multiple diseases from a single application
- User-friendly web interface
- Machine Learning-based predictions
- Separate trained models for different diseases
- Fast and interactive predictions using Streamlit

---

## 🛠️ Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Scikit-learn
- Pickle
